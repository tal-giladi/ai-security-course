# Module 30 quiz — AI infrastructure & deployment exploits

This quiz covers the AI infrastructure attack surface — model/inference servers, ML lifecycle
services, cluster dashboards, notebooks, and containers — the two dominant deployment flaws
(unauthenticated management surfaces and path traversal / SSRF), and the control ranking: network
exposure first, then authentication and input validation as multiplicative defence-in-depth.

Ten scenario questions. Pass mark **70%**. If a question is hard, revisit
[30.1 · AI infrastructure & deployment exploits](../lessons/module-30/lesson-01.md), especially the
gate model P(success) = r · f · a and the guarantee analysis for network exposure control.
