# Module 31 quiz — Full-spectrum AI red-team engagement

This quiz covers running an AI red-team engagement end to end: scope and rules of engagement, the
recon → foothold → lateral → objective → report lifecycle, chaining findings into impact, prioritising
remediation by leverage (the link that breaks the chain), the guarantee-analysis habit in every
finding, and mapping to MITRE ATLAS / OWASP LLM Top 10 / NIST AI RMF.

Ten scenario questions. Pass mark **70%**. If a question is hard, revisit
[31.1 · Full-spectrum AI red-team engagement](../lessons/module-31/lesson-01.md) and the engagement
report template [`templates/engagement-report.md`](../templates/engagement-report.md).
