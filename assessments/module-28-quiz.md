# Module 28 quiz — Multi-agent systems & A2A

This quiz covers attacking and defending multi-agent (A2A-style) systems: the trust graph and message
lifecycle, the four attack classes (impersonation, message tampering, workflow corruption, capability
over-claim), transitive trust, and the edge-level defenses — message authentication, sender
verification, per-edge capability scoping, and task provenance.

Ten scenario questions. Pass mark **70%**. If a question is hard, revisit
[28.1 · Attacking multi-agent systems & A2A protocols](../lessons/module-28/lesson-01.md), especially
the transitive-trust risk model and the guarantee analysis for message authentication.
