# Module 2 quiz — LLM security foundations

This quiz covers where the boundary between instruction and data really is: tokenization, the context window, the message hierarchy, why instruction-following is statistical rather than enforced, and the attack surface of the inference API itself (streaming, structured output, tool calling).

Scenario questions, not recall: you are given a situation and asked what to do, what it costs, and what it does not stop. Pass mark **70%**.
