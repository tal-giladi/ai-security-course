# Module 27 quiz — Reconnaissance for AI targets

This quiz covers reconnaissance for AI-enabled systems: passive vs active recon, model and stack
fingerprinting, asset and infrastructure enumeration, the information-per-noise objective, and the
defensive inverse (surface reduction and detection).

Ten scenario questions. Pass mark **70%**. If a question is hard, revisit
[27.1 · Reconnaissance for AI targets](../lessons/module-27/lesson-01.md) — especially the
Mathematics (information gained vs detection cost) and the guarantee analysis for output
normalisation.
