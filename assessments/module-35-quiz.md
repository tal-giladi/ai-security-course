# Module 35 quiz — Agentic vulnerability discovery

This quiz covers the iFinder / implicit-trust-error (iTrue) case study: how an LLM multi-agent system (Discovery → Vetting → Exploitation) finds, vets and triages real vulnerabilities, how to read its evaluation (precision/recall/F1, the ablation, PoC-validation as a judge), and the defensive root-cause lessons — syntactic, semantic and resource-availability validation at a trust boundary, the uniqueness invariant, and bounded allocation.

Scenario questions, not recall: you are given a situation and asked what to do, what it costs, and what it does not stop. Pass mark **70%**.
