# Module 29 quiz — Embedding attacks

This quiz covers embedding inversion and attribute extraction: why embeddings are recoverable data
rather than anonymising hashes, how nearest-token inversion and linear-probe extraction work, the
noise-vs-utility trade-off, and the defense priority order (access control and minimisation first,
noise/DP as measured defence-in-depth).

Ten scenario questions. Pass mark **70%**. If a question is hard, revisit
[29.1 · Attacking embeddings: inversion & extraction](../lessons/module-29/lesson-01.md), especially
the Mathematics (why the trade-off is unavoidable) and the guarantee analysis for additive noise/DP.
