# The trust-region effect: where an injection is placed changes compliance

- **Topic ID:** injection-placement-trust-region

## Summary

With content held fixed, a GPT-5.4 agent followed an unsafe instruction placed in README/TODO files about 2.6× more often than the same instruction in code or data files. Learned attackers optimize content and placement jointly.

## Evidence

- https://arxiv.org/abs/2610.38867 — Guo et al. (Bo Li, Jianfeng Gao co-authors), preprint, no code.
