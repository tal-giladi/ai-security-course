# Agents as fraud victims (earn-then-exploit, scam environments)

- **Topic ID:** agent-fraud-susceptibility

## Summary

Web and coding agents can be defrauded like users: an attacker earns trust with benign interactions and then exploits it (earn-then-exploit, 56 environments x 3 agents), and interactive scam environments measure deception rates of 11–35% across six frontier LLMs. The other half of the fraud threat model to `agent-adaptive-phishing` (agents generating fraud).

## Evidence

- C-20261103-01 — Long Con on the Web (preprint, no code).
- C-20261105-03 — ScamWorld (preprint, code released).

## What would change the decision

Independent replication of either result, or a defense with measured utility cost; then a joint lesson with agent-adaptive-phishing (M16/M18).
